# Python + FastAPI Example

A minimal runnable example demonstrating Halo with a Python API project, and the
no-regression guard for the FastAPI route parser.

## What's Included

```
examples/py-fastapi/
├── try-it.sh                          # Runs every gate against this project
├── pyproject.toml                     # Project metadata (mock, not installed)
├── halo/
│   ├── manifest.yaml                  # Halo project config
│   ├── specs/
│   │   └── model-set-api/
│   │       ├── spec.md                # Sample spec with Context Basis and AC-1 through AC-4
│   │       └── review.md              # Generated by try-it.sh
│   └── context/
│       ├── sources.yaml
│       ├── README.md                  # Agent context map
│       └── knowledge/
│           ├── architecture.md
│           ├── glossary.md
│           ├── pitfalls.md
│           └── rules.md               # Sample naming rules
├── app/
│   ├── errors.py                      # Business error codes (matches spec error table)
│   └── routers/
│       ├── model_sets.py              # APIRouter with prefix, empty-path collection root,
│       │                              # single-line and multi-line decorators
│       └── members.py                 # Multi-line APIRouter prefix, `"/"` collection root
└── tests/
    └── test_model_sets.py             # Tests named test_ac1_ through test_ac4_
```

## Try It

```bash
# From the repo root:
bash examples/py-fastapi/try-it.sh
```

## What You'll See

- **spec-lint**: Validates required sections, sequential AC numbers, decision log
- **prismspec-lint**: Validates the PrismSpec artifact contract
- **ac-coverage**: Maps AC-1 through AC-4 to `test_ac1_list_model_sets`, … — 100% coverage
- **drift-check**: Resolves all six spec routes against `APIRouter` prefixes plus decorator
  paths, and matches the spec error code table against `app/errors.py`
- **drift-check honesty**: SQLAlchemy DDL comparison is not implemented, so the DDL
  dimension is reported as **NOT verified** rather than as clean
- **context knowledge backend**: Searches "naming" → returns `knowledge/rules.md`

## Why The Routers Look Like This

`app/routers/` is not written for brevity — it is written to carry the registration
styles a real FastAPI project uses, because drift-check reads route declarations out of
source text:

| Shape | Where | What it guards |
|-------|-------|----------------|
| `@router.get("")` under a router prefix | `model_sets.py` | The collection root has an empty decorator path; the prefix carries the whole URL |
| `@router.put(\n "/{set_id}",\n …)` | `model_sets.py` | Decorators spanning several lines |
| `APIRouter(\n prefix=…,\n)` | `members.py` | Router prefixes spanning several lines |
| `@router.get("/")` | `members.py` | The trailing-slash form of a collection root |

A parser that only understands one of these reports the others as drift. `try-it.sh`
step 5 asserts that all six spec routes resolve with `drift_count == 0`, so that failure
lands here rather than in a target project.
